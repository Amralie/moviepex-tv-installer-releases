# Moviepex TV Installer

Downloads for the Moviepex TV Installer, the desktop tool that puts Moviepex on an LG or Samsung TV.

Get the newest version from the Releases page on the right, or from https://moviepex.com/download

- Windows: `Moviepex-TV-Installer-<version>-setup.exe`
- Linux: the `.AppImage` or the `.deb`

The installer updates itself from this repository.
